# 🌊 ADA - Acoustic Design Assistant

The app is a stand alone app for Mac. The methodology for the "Acoustic Design Assistant" (ADA) follows a Research through Design (RtD) approach. 

## Methodology
The project will utilize an Iterative Prototyping Model, with development divided into distinct functional "Sprints". The methodology is structured into four distinct phases:
* **Phase 1:** Theoretical Foundation & Expert Validation (Requirements).
* **Phase 2:** The Core Logic Sprints (Iterative Development).
* **Phase 3:** Integration & User Verification (Synthesis).
* **Phase 4:** Final Evaluation & Documentation.

## Features
* **Modal Analysis:** Low-frequency behavior calculation using the Rayleigh Equation, including Bolt Area Stability checks.
* **RT60 Calculator:** Reverberation time estimates using both Sabine and Eyring formulas.
* **SBIR Analysis:** Speaker-Boundary Interference Response modeling for front wall, side wall, and floor distances.
